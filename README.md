# 六星手帳

生年月日を一度登録すると、開いた時に今日・今月・今年の運気を表示する、スマホ向けの非公式アプリです。

**v1.0.0 / 2026年10月2日**

## GitHubで公開する（パソコン不要）

1. ダウンロードした `rokusei-app-v1.0.0.zip` を「ファイル」アプリでタップして解凍します。
2. GitHubで新しいリポジトリを作成します。名前の例は `rokusei`、公開範囲は **Public**。READMEを追加して作ると、アップロード画面を見つけやすくなります。
3. リポジトリで **Add file → Upload files** を選びます。スマホでは「＋」や「…」の中にある場合があります。
4. 解凍したフォルダの **中身のファイル一式** をアップロードします。ZIPそのものではありません。`index.html`、`app.js`、`engine.js`、`data.js`、`style.css`、`sw.js`、`manifest.webmanifest`、`icon.svg`、3つのPNGアイコンが同じ階層に必要です。READMEも一緒に入れられます。テスト用フォルダは公開に必須ではありません。
5. **Commit changes** で保存します。リポジトリの最上段に `index.html` が見えることを確認します。外側のフォルダごと入れないでください。
6. **Settings → Pages → Source: Deploy from a branch → Branch: main → /(root) → Save** を選びます。
7. 公開後、Pages画面の **Visit site** から開きます。反映には数分かかる場合があります。URLは通常 `https://あなたのGitHubユーザー名.github.io/rokusei/` です。リポジトリ名を変えた場合は、その名前になります。

`.nojekyll` は任意です。隠しファイルが選べなくても、この構成は動きます。

GitHubの案内： https://docs.github.com/en/pages/quickstart

## ホーム画面から使う

**iPhone / iPad**

Safariで公開URLを開く → 共有 → ホーム画面に追加 → 追加。
**追加したアイコンから開いて生年月日を登録**してください。Safariとホーム画面のアプリで保存データが分かれる環境では、設定のバックアップと復元で引き継げます。

**Android**

Chromeで公開URLを開く → メニュー → ホーム画面に追加 / アプリをインストール。

初回は通信が必要です。設定の「オフラインの準備ができています」を確認すると、次回は通信がなくても起動・計算できます。アプリを削除したり、端末がサイトデータを削除すると、再度オンラインで開く必要があります。

## 入っている機能

- 生年月日の保存、運命星・＋／−・霊合星人の自動判定（24タイプ）
- 今日・今月・今年のメイン運気、霊合星人のサブ運気
- 恋愛・家庭、仕事・勉強、お金、人間関係の生活のヒント
- 日運カレンダー、12か月の月運、12年の年運一覧
- 6星それぞれの詳細8項目（長所、注意点、恋愛、家庭、仕事、お金、人間関係、気持ちの整え方）
- 相手の生年月日を使う性格傾向の比較と、二人の年運表示
- ホーム画面用アイコン、オフライン起動、更新のお知らせ
- 登録内容の変更・削除、JSONバックアップの保存・復元
- 日本時間の日付を使用。画面復帰時と30秒ごとの確認で日付を更新

会員登録、外部API、AIの課金、ビルド作業は不要です。外部フォントやCDNにも依存しません。

## 判定と解説の扱い

星数は、2000年1月1日を55とする60日周期の日干支番号を使い、1〜10=土星、11〜20=金星、21〜30=火星、31〜40=天王星、41〜50=木星、51〜60=水星に分類します。生まれ年の十二支は暦年で扱い、立春による補正はしません。

年運は年の十二支、月運は暦月、日運は日の十二支から、それぞれ12段階を計算します。土星＋の年・日運は子が種子、月運は12月が種子。他の星は土星から2段階ずつ進み、−は＋より1段階前です。霊合星人は生まれ年の十二支が停止に対応する場合。サブの星は土星↔天王星、金星↔木星、火星↔水星で、運気は6段階離れます。

**運気名は計算、文章は独自解説**です。12日後の同じ運気は同じ基本解説になり、月運は同じ星なら毎年同じ月に同じ運気です。毎日AIが新しい鑑定文を生成する仕組みではありません。＋／−の違いは運気に反映し、基本の性格は6星共通の分類で説明しています。

相性画面は星ごとの性格傾向を比べる独自の読み物で、公式の相性順位・相性鑑定を再現したものではありません。公式の毎日更新の有料鑑定文、宿命大殺界、方位鑑定、ラッキーカラーは含みません。

## 登録情報とバックアップ

登録情報は端末のlocalStorageに保存します。生年月日を外部サーバーに送信しません。解析・広告・ログイン機能もありません。サイトの公開サーバーへの通常のアクセス通信はあります。

バックアップには生年月日とニックネームが含まれます。**バックアップJSONを公開リポジトリにアップロードしないでください。** バックアップの共有・保管は本人が管理してください。端末・ブラウザごとの保存となり、自動クラウド同期はありません。

## 更新方法

変更したファイルをGitHubに上書きします。`app.js`、`sw.js`内のバージョンと画面・READMEのバージョン表記も揃えて更新します。特に `sw.js` の `VERSION` を変えることで、新しいファイル一式を別キャッシュとして保存します。

オンラインでアプリを開き、上部の「更新する」を押すと新しい版に切り替わります。登録情報は保持します。「更新する」が見つからない時は、設定の「アプリの更新を確認」を押します。

## 開発用

Node.jsがあれば、計算のテストを実行できます。

```sh
node --test tests/engine.test.cjs
```

ローカルで試す時は、HTTPサーバーで開きます。

```sh
python3 -m http.server 8080
```

`http://localhost:8080/` を開いてください。ファイルを直接開くと、一部の環境では表示できますが、オフライン保存・ホーム画面用機能には公開URLまたはlocalhostが必要です。

## ファイル構成

| ファイル | 役割 |
|---|---|
| index.html / style.css | 画面とスマホ向けのデザイン |
| engine.js | 判定・日付・運気計算 |
| data.js | 星・運気・独自解説 |
| app.js | 保存・画面操作・バックアップ |
| sw.js | オフラインと更新 |
| manifest.webmanifest / icon-* / icon.svg | ホーム画面に追加するための設定・アイコン |
| tests/engine.test.cjs | 公開資料との照合・日付境界のテスト |
